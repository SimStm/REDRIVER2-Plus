# Archived ideas and historical graphics records

This directory is excluded from routine analysis, searches, and agent context.
Read its documents only when the user explicitly requests historical review.
Historical links elsewhere do not override that requirement.

The `2026-10-06-rendering-reset/` snapshot contains the former renderer
discussions, superseded graphics plans, specific graphics product/change
records, diagrams, and hybrid bridge rules. `manifest.json` records each old
path, destination, original SHA-256 and byte count. Moves were byte-exact;
relative links are subsequently maintained, with final hashes recorded separately.

Archiving documentation does not remove the implemented code or invalidate
earlier executed tests. The active source-backed baseline and replacement plan
are in `knowledge/rendering/`. Historical scopes and limitations are not the
new renderer's requirements. Original game assets were not moved.
